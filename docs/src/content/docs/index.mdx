## New way to juice your games just dropped!

tweens.gd is a fully free and libre open source tweening system for the [Godot game engine](https://godotengine.org/).  
This addon aims for concise and consistent syntax, and more [flexible easing options](/easings/) than most.



### tweens.gd respects your <u>time</u> and your <u>keycaps.</u>

var tween = sprite.CreateTween();

### Huh... what even is all this?
<Aside type="tip" title="'Tweening' means..."><p>...using code to animate nodes and resources, changing their properties like position or color over time by ~~soft paws~~ smooth functions called "easings."</p>
<p>Whole game worlds can be animated this way, but your classic use cases are button clicks, squash and stretch effects, wiggles, hover, punches, fades, bounces, ... ["juice it or lose it".](https://www.youtube.com/watch?v=Fy0aCDmgnxg)</p></Aside>
