tweens.gd includes both C# and GDScript in one addon. Its GDScript runtime is
independent: there is no plugin to activate, no autoload, and no .NET runtime or
GDExtension to install. The bundled C# files can stay in a GDScript-only project.

:::note[Beta]
The GDScript API may change during beta. [Compatibility](/compatibility/) lists
what has been validated.
:::

## Add the addon

The unified package is prepared for the [Godot Asset Store](https://store.godotengine.org/).
Until a public version is available, take it from a clone of the repository,
either as a directory or as a ZIP you build yourself.

<Tabs>
<TabItem label="Copy the directory">

Copy the repository's `addons/tweens_gd/` directory into your project's `addons/`
directory, so the entry script sits at `res://addons/tweens_gd/tweens.gd`. Copy
the whole directory, including `LICENSE` and `THIRD-PARTY-NOTICES.md`.

</TabItem>
<TabItem label="Addon ZIP">

<Steps>

1. From the repository root, build the ZIP. The version defaults to the C#
   package's version:

   ```powershell
   ./scripts/Pack-Addon.ps1
   ```

   This writes `artifacts/packages/tweens.gd-0.1.0-pre.zip`, including both languages.

2. Unpack it into your project's root directory. Its entries already start with
   `addons/tweens_gd/`.

</Steps>

</TabItem>
</Tabs>

## Load it from a script

The entry script registers the global class `Tweens`. Use it directly, with no
preload or autoload:

```gdscript
await Tweens.play(self, Tweens.position_2d(Vector2(100, 50), 0.3)).end
```

Let the editor finish importing before running the project. For a fresh
headless checkout, run `godot --headless --editor --import` once to populate the
script-class cache used by the addon's internal types.

Then write [your first tween](/gdscript/quickstart/).
