tweens.gd is free and libre open source under the [MIT license](https://github.com/outfox/tweens.gd/blob/main/LICENSE).
You can build it from source or get prebuilt versions through these official channels.

## Let's... *ease* into it

Choose where to download the addon:

<InstallOptions>
<div slot="store">

### Godot Store

Get the shared addon with support for both C# and GDScript.

1. Download it from the [Godot Store](https://store.godotengine.org/asset/outfox/tweens/).
2. Unpack it into your project root, keeping the entire `addons/tweens_gd/` directory.

</div>
<div slot="alternative">

### GitHub Releases

Get the addon ZIP from [GitHub Releases](https://github.com/outfox/tweens.gd/releases).
Alongside the combined addon, releases will also offer lightweight GDScript-only builds.

Choose the packaged addon from the release assets, then unpack it into your project root.

</div>
</InstallOptions>

## Build your project

Keep the entire `addons/tweens_gd/` directory so its scripts, native libraries, and
licenses stay together. The entry script should be at `res://addons/tweens_gd/tweens.gd`.
If you choose the combined addon, its C# files can stay in a GDScript-only project.

<span id="load-it-from-a-script" />

Once tweens.gd is installed and Godot is running, you're ready to write
[your first tween](/gdscript/quickstart/).

## Odds and ends

To export your game to the Web, turn on **Extensions Support** in the export preset.
