<GdCatalog section="Any node" />

## Units and constraints

- GDScript represents both `float` and `double` as `float`. `double_value` exists
  to match the C# catalog.
- With no `from_value` or `to_value`, the definition uses zero, transparent black,
  or identity for that endpoint.
