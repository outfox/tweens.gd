Helpers for `Node3D`, `GeometryInstance3D`, and the 3D node classes.

Each row pairs a helper with the C# definition it mirrors. Names ending in `_x`,
`_y`, `_z`, or `_alpha` write one component.

<GdCatalog section="3D" />

## Units and constraints

- `global_quaternion_3d` interpolates along the shortest quaternion path, then
  writes the global rotation.
- `geometry_instance_3d_transparency` is an amount of transparency (0 opaque,
  1 transparent), not opacity.
- Path helpers require a `PathFollow3D` under a `Path3D` with a nonempty curve.
  The node still controls looping and wrapping.
