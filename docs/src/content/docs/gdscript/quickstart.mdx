Move a sprite, then fade it out once it arrives. Along the way you define a
tween, start it on the sprite, and await it before continuing.

<Steps>

1. [Install the addon](/gdscript/installation/) in your Godot project.

2. Create a scene with a `Sprite2D` and give it a texture.

3. Attach this script as `move_and_fade.gd`, then play the scene. The sprite
   glides 240 pixels to the right, settles, and fades out.

</Steps>

## The script, line by line

<Moves>

```gdscript title="move_and_fade.gd" {"1":6-7} {"2":9} {"3":10} {"4":12}
extends Sprite2D

const Tweens = preload("res://addons/tweens_gd/tweens.gd")

func _ready() -> void:
	var target := position + Vector2(240, 0)
	var arrive := Tweens.position_2d(target, 0.6, Tweens.Ease.CUBIC_OUT)

	var movement := Tweens.play(self, arrive)
	await movement.end

	await Tweens.play(self, Tweens.modulate_alpha(0.0, 0.3)).end
```

1. **Define.** `Tweens.position_2d(to, seconds, easing)` returns a definition
   for a `Node2D`'s `position`. The definition is an ordinary object whose
   other settings, such as `delay` or `repeats`, are fields you can set before
   you start it. `from_value` stays `null`, so the tween starts wherever the
   sprite is.
2. **Start.** `Tweens.play(self, arrive)` starts playback and returns a handle.
   The first tween sets up its own runner, so there's no autoload to add.
3. **Await.** `await movement.end` waits until playback ends. Here we ignore the
   returned reason and continue with the fade.
4. **One line.** A helper takes the endpoint and duration, so a one-off tween
   is a single call. If you start the same motion in several places or expect to
   adjust it, keep the definition in a variable instead, so its settings live in
   one place.

</Moves>

Start tweens from `_ready()` or later, on a node inside the tree, on Godot's main
thread.

Await also resumes after cancellation. For an animation that can be interrupted,
[check the reason before starting the next step](/gdscript/cancellation/).

## Control it while it plays

Keep the handle to pause, resume, or cancel:

```gdscript
var movement := Tweens.play(sprite, Tweens.position_2d(Vector2(400, 180), 0.6))
movement.pause()
movement.resume()
movement.cancel()
```

Cancelling keeps the latest value. To stop every tween the sprite and its
descendants own, call `Tweens.cancel_tweens(sprite, true)`.

## Make it reusable

A definition isn't tied to a node, so one `arrive` can start on any number of
sprites. A Godot `Tween` is built for one node and can't be reused, so each
sprite needs its own:

<Compare>

```gdscript title="Godot's Tween"
var target := Vector2(400, 180)

var tween1 := sprite1.create_tween()
tween1.set_trans(Tween.TRANS_CUBIC).set_ease(Tween.EASE_OUT)
tween1.tween_property(sprite1, "position", target, 0.6)

var tween2 := sprite2.create_tween()
tween2.set_trans(Tween.TRANS_CUBIC).set_ease(Tween.EASE_OUT)
tween2.tween_property(sprite2, "position", target, 0.6)
```

```gdscript title="tweens.gd"
var arrive := Tweens.position_2d(Vector2(400, 180), 0.6, Tweens.Ease.CUBIC_OUT)

Tweens.play(sprite1, arrive)
Tweens.play(sprite2, arrive)
```

</Compare>

In the script above, `arrive` lives inside `_ready()`, so nothing else can use
it. Move it to a `static var` and give it `.with_by(Vector2(240, 0))` instead of
a `to_value`, and any node can start it unchanged: each one moves 240 pixels from
where it is. The next page,
[definitions](/gdscript/definitions/), shows how.
