Make a sprite glide 240 pixels to the right, then fade out. You'll write one
short script and run it in a scene.

<Steps>

1. [Install the addon](/gdscript/installation/) in your Godot project.

2. Create a scene with a `Sprite2D`, give it a texture, and place it where there
   is room to move right in the viewport.

3. Attach the script below as `move_and_fade.gd`, then play the scene.

</Steps>

<span id="the-script-line-by-line" />

## Move, then fade

<Moves>

```gdscript title="move_and_fade.gd" {"1":4-5} {"2":7} {"3":8} {"4":10}
extends Sprite2D

func _ready() -> void:
	var target := position + Vector2(240, 0)
	var arrive := Tweens.position_2d(target, 0.6, Out.CUBIC)

	var movement := Tweens.play(self, arrive)
	await movement.end

	await Tweens.play(self, Tweens.modulate_alpha(0.0, 0.3)).end
```

1. **Choose the move.** `arrive` moves the sprite 240 pixels right in 0.6 seconds.
   `Out.CUBIC` makes it slow into place.
2. **Start moving.** `Tweens.play(self, arrive)` plays the motion on this sprite.
   Keep its handle in `movement` to wait for it.
3. **Wait before fading.** `await movement.end` lets the movement finish before
   the script continues.
4. **Fade out.** The final call lowers the sprite's opacity to zero over 0.3 seconds.

</Moves>

Experiment with the values in the tween definition to get a feel for duration.
