To compare the built-in curves, open the [easing playground](/easings/).

See the [easing reference](/gdscript/api/easing/) for join methods, curve
percentages, and migration from legacy names. For changing the pacing without
changing families, see [`skew` and `weks`](/gdscript/variations/#change-the-pacing-with-skew).

### Effects
For ready-made punch, shake, and breathing motion, use
[effect factories](/gdscript/api/effects/).

### Custom functions and curves

For a shape the built-in families don't cover, supply a function from normalized
progress to an interpolation weight:

```gdscript
var move := Tweens.position_2d_x(300.0, 0.6)
move.ease_function = func(t: float) -> float: return t * t
Tweens.play(sprite, move)
```

`ease_function` overrides `ease`. 

A Godot `Curve` assigned to `curve` is another
option; each playback gets its own copy. Set only one of `ease_function` and `curve`.
