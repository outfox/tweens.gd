Awaiting a tween resumes when it ends, including cancellation. Check the reason when the next action requires a successful arrival.

Examples use the global `Tweens` class in a node script, with targets inside the scene tree.

## Cancel playback

Call `movement.cancel()` to stop a tween. Its latest value stays visible and its waiters resume. Cancellation does not stop the surrounding coroutine.

<Aside type="tip" title="Cancel a whole animation">

Groups and Chains expose the same controls. To cancel everything owned by a node and its descendants, use `Tweens.cancel_tweens(sprite, true)`.

</Aside>

## Continue only on success

```gdscript
var movement := Tweens.play(sprite, Tweens.position_2d([400, 180], 0.6))
if await movement.end != Tweens.Reason.COMPLETED:
    return

await Tweens.play(sprite, Tweens.modulate_alpha(0.0, 0.3)).end
```

The fade runs only after arrival. The early return also avoids starting it on a target that was freed during movement.

## Why it ended

| Reason | Meaning |
| --- | --- |
| `COMPLETED` | Reached the natural end |
| `CANCELLED` | Cancel was called |
| `TARGET_FREED` | Target was freed or queued for deletion |
| `OWNER_EXITED` | Owner left the tree |
| `RUNNER_DISPOSED` | Tree or scheduler shut down |
| `FAILED` | Start or playback detected a problem; read `error` |
| `WAIT_CANCELLED` | Only the wait was cancelled |

<Aside type="note" title="Tree exit can happen first">

Freeing a node can report `OWNER_EXITED` because Godot emits tree exit before invalidating it. Both mean playback stopped early.

</Aside>

## Cancel a wait, not the tween

`wait(cancellation)` with a `TweensGdCancellation` lets one caller stop waiting while playback and other waiters continue.

A cancelled wait returns `WAIT_CANCELLED`; it does not change the handle’s completion reason.

See [handle wait helpers](/gdscript/api/handles/) for the API and [errors](/gdscript/api/handles/#errors) for failure handling.
