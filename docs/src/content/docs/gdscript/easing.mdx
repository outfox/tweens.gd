Easing changes how speed varies during a tween. Start with `Tweens.Out.CUBIC` for a
motion that slows into place; duration still controls how long it takes.

Examples use the global `Tweens` class, with an in-tree `Sprite2D`
named `sprite` on Godot's main thread.

## Choose a family

```gdscript
var move := Tweens.position_2d_x(300.0, 0.6, Tweens.Out.CUBIC)
Tweens.play(sprite, move)
```

| Motion | Try |
| --- | --- |
| Arrive and settle | `Tweens.Out.CUBIC` |
| Accelerate away | `Tweens.In.CUBIC` |
| Move between resting positions | `Tweens.InOut.SINE` |
| Spring past the target, then settle | `Tweens.Out.ELASTIC30` |
| Keep a constant speed | `Tweens.InOut.LINEAR` |

`In` accelerates into the motion; `Out` eases out of it. `InOut` combines a
family's start and finish. These describe each traversal, not the forward and
return legs of ping-pong.

## Compare the curves

**Try it:** play **Sine in & out**, then **Spring finish**. Watch how the spring
passes its destination before settling. The generated code follows your choices.

## Compose an ease

Combine one In family and one Out family with `|`: `Tweens.In.SINE | Tweens.Out.CUBIC` starts gently
and finishes with Cubic. Choose at most one from each side. A single selection
runs over the whole duration; a matching pair is the same as `InOut`.

Mixed families use a smooth Makima join by default. Most motions need no
adjustment. `blend` sets the join width from 0 to 1; a smaller width preserves
more of the original halves. Matching pairs and single curves ignore it.

## Custom functions and curves

For a shape the built-in families don't cover, supply a function from normalized
progress to an interpolation weight:

```gdscript
var move := Tweens.position_2d_x(300.0, 0.6)
move.ease_function = func(t: float) -> float: return t * t
Tweens.play(sprite, move)
```

`ease_function` overrides `ease`. A Godot `Curve` assigned to `curve` is another
option; each playback gets its own copy. Set only one of `ease_function` and `curve`.
