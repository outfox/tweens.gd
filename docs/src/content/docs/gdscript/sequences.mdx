Use a **Chain** to put several motions on one target's timeline. Use a **Group** when independent tweens should play together.

Examples use the global `Tweens` class in a node script, with targets inside the scene tree.

## Play in order

```gdscript
var animation := Tweens.chain(sprite, [
    Tweens.position_2d([400, 180], 0.6),
    Tweens.scale_2d([1.2, 1.2], 0.2),
    Tweens.modulate_alpha(0.0, 0.3),
])
await animation.end
```

The sprite moves, grows, then fades. Each step captures its starting value when it activates, so it sees the preceding step's result.

## Overlap and gaps

Each entry's delay is relative to the previous entry's end. A positive delay adds a gap; a negative delay overlaps:

```gdscript
var animation := Tweens.chain(sprite, [
    Tweens.position_2d([400, 180], 0.6),
    Tweens.modulate_alpha(0.0, 0.3).with_delay(-0.2),
])
```

The fade starts at 0.4 seconds, while movement continues to 0.6. The Chain ends at 0.7 seconds.

## Play together

```gdscript
var together := Tweens.play_all(sprite, [
    Tweens.position_2d([400, 180], 0.6),
    Tweens.modulate_alpha(0.0, 0.6),
])
await together.end
```

Group handles from different targets with `Tweens.group([first, second])`. Pause, resume, or cancel through the returned controller.

<Aside type="tip" title="When to use await">

Use ordinary awaits for decisions, user input, and transitions between targets. Use a Chain when motions need a shared timeline: separate starts after an await begin on the next eligible update.

</Aside>

See the [Chain reference](/gdscript/api/chains/) for pre-roll, capture order, and limits, or [Groups](/gdscript/api/groups/) for parallel completion rules.
