Derive a stronger, slower, or later version of one definition. Factors multiply its values; deltas add to them when playback starts.

Examples use the global `Tweens` class in a node script, with targets inside the scene tree.

<span id="a-complete-example" />
<span id="factors-and-deltas" />

## Scale a motion

```gdscript
var recoil := Tweens.position_2d_x(null, 0.2, InOut.QUAD) \
    .with_by(-12.0).with_ping_pong()

Tweens.play(sprite, recoil.with_factor_by(2.0).with_factor_duration(1.2))
```

This hit moves 24 pixels and takes 0.24 seconds each way. Tune the original distance or duration, and the factored version follows.

<Aside type="tip" title="Multiply, then add">

`with_factor_duration(2.0)` doubles the original duration. `with_delta_delay(0.1)` adds a tenth of a second to its delay. `with_duration()` instead gives the copy a fixed duration.

</Aside>

## Vary the current value

Leave the destination unset and scale the captured value:

```gdscript
var beat := Tweens.scale_2d(null, 0.15, InOut.SMOOTHER_STEP) \
    .with_factor_to(1.2).with_ping_pong()
Tweens.play(sprite, beat)
```

The sprite grows to 120% of its current scale and returns. Use `with_delta_delay()` for a stagger that preserves the definition's own delay.

<span id="change-the-pacing-with-skew" />

## Change the pacing

`skew` controls the outward In/Out split; `weks` controls the return. Each ranges from 0 (front-loaded) to 1 (rear-loaded), with 0.5 balanced. Set the return split to one minus the outward split to retrace the curve.

**Try it:** increase hit strength, then adjust the outward split. The distance changes with the factor; pacing changes with the split.

<VariationLab lang="gdscript" />

<Aside type="note" title="Paired easing only">

The split controls apply to paired In/Out flags. Custom functions, Godot Curves, and single easing legs keep their authored shape.

</Aside>
