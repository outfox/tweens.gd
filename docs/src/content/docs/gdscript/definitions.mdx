A definition describes a motion independently of the node playing it. Keep one
definition for motion you reuse; each start gets its own snapshot.

Examples use the global `Tweens` class and run on Godot's main thread with nodes
inside the tree.

<span id="keep-definitions-in-static-variables" />

## Define once, start twice

Keep the definition in a `static var` so every instance can use it:

```gdscript title="crate.gd"
extends Node2D

static var nudge := Tweens.position_2d(null, 0.2, Tweens.Out.CUBIC) \
	.with_by(Vector2(80, 0))

func push_pair(first: Node2D, second: Node2D) -> void:
	Tweens.play(first, nudge)
	Tweens.play(second, nudge)
```

Both nodes move 80 pixels right from their own positions. Editing `nudge` tunes
the motion in one place. Starting it returns a separate handle for each node.

## Leave out `from_value` or `to_value`

Use `to_value` for a destination, or `from_value` for an entrance:

| Definition | Motion |
| --- | --- |
| `Tweens.position_2d(Vector2(400, 180), 0.4)` | Move from the current position to a fixed destination |
| `Tweens.scale_2d(null, 0.4).with_from(Vector2.ZERO)` | Grow from zero to the scale set in the scene |

An endpoint left at `null` is read from the property **when you start the tween**,
before any delay. Set both endpoints when both must be fixed.

## Move by an offset with `by_value`

`nudge` uses `with_by()` to add an offset. Other changes to the property are kept
while it plays: two overlapping nudges move a crate 160 pixels in total.

Use either `to_value` or `by_value`. Leave `from_value` out for this additive
motion; setting it makes the tween run between fixed endpoints, from
`from_value` to `from_value + by_value`.

## Vary a start with `with_*()`

In `push_pair`, replace the second call with
`Tweens.play(second, nudge.with_duration(0.6))`.

`with_duration()` returns a modified copy. The second node takes longer, but
`nudge` still has a duration of 0.2 seconds. Neither copy changes a tween already
playing.

:::caution[Keep shared definitions read-only]
GDScript definitions are mutable objects. Assigning `nudge.duration = 0.6`
changes it for every later start. Use a `with_*()` copy to change just one start.
:::

**Try it:** change the second node's duration and press **Play both**. Both travel
the same distance; the first always takes 0.2 seconds.
