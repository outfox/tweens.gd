Animate a material to change every node using it. Use an instance uniform when each node needs its own shader value.

Examples use the global `Tweens` class in a node script, with targets inside the scene tree. Materials below are configured resources; `mesh` is a `MeshInstance3D` using them.

## Choose the playback lifetime

Resources need an explicit lifetime. Use a node owner for an effect attached to that node, or the tree for an effect that should outlive it:

```gdscript
var smooth := Tweens.material_roughness(0.2, 1.0)
Tweens.play(material, smooth, mesh)       # Stop when mesh leaves the tree.
Tweens.play(material, smooth, get_tree()) # Stop when the tree shuts down.
```

These are alternative lifetime choices. Changing a mesh's material does not retarget a running tween.

## Built-in material properties

Use the [material catalog](/gdscript/nodes/materials/) for albedo, roughness, emission, and UV helpers. They target `BaseMaterial3D`.

<Aside type="caution" title="Sharing is visible">

Tweening a shared resource changes all its users. For independent values, duplicate and assign the material once during scene setup.

</Aside>

```gdscript
var unique: StandardMaterial3D = shared.duplicate()
mesh.material_override = unique
Tweens.play(unique, Tweens.material_albedo_color(Color.RED, 1.0), mesh)
```

<Aside type="tip" title="Enable the feature first">

Alpha fading needs transparency; emission and normal mapping need their flags enabled. Tweens change values, so configure the material for the visible effect before starting playback.

</Aside>

## Ordinary shader uniforms

For a shader declaring `uniform float dissolve = 0.25;`:

```gdscript
Tweens.play(shader_material, Tweens.shader_parameter(&"dissolve", 1.0, 0.5), mesh)
```

This changes the shared material's uniform. Names are case-sensitive and endpoints must match the declared type. Use `1.0` for a float uniform; `1` is an integer. Use `Color` for color uniforms.

## Per-instance shader uniforms

For a shader declaring `instance uniform float pulse = 0.25;`:

```gdscript
Tweens.play(mesh, Tweens.instance_shader_parameter(&"pulse", 1.0, 0.5))
```

Only this node's instance value changes, even when it shares the material. Playback follows the node's normal lifetime.

<Aside type="caution" title="Keep bindings stable">

Replacing a bound shader or material can fail playback. Start a new tween after changing the binding. Shader default lookup also needs a working renderer.

</Aside>

The [material and uniform reference](/gdscript/nodes/materials/#ordinary-shader-uniforms) covers supported types, validation, defaults, and restoring overrides.
