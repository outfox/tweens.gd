## Two API flavours

<Compare>

**Structured** creates a definition object to reuse, or to vary with `with_*()` copies.

```gdscript title="Structured"
var arrive := Tweens.position_2d([400, 180], 0.6, Out.CUBIC)

Tweens.play(sprite, arrive)
```

---

**Convenient** creates and starts a local animation in one `Tweens.play()` expression.

```gdscript title="Convenient"
Tweens.play(sprite, Tweens.position_2d([400, 180], 0.6, Out.CUBIC))
```

GDScript uses helpers rather than node extensions.

</Compare>

These are alternative ways to start the same motion. Both return a handle when played.

## Safe and sweet endpoints

<Compare>

A Godot value states the endpoint's type explicitly.

```gdscript title="Safe: explicit type"
Tweens.play(sprite, Tweens.position_2d(Vector2(400, 180), 0.6))
```

---

An array of components is shorter, and the start converts it to the expected type.

```gdscript title="Sweet: array"
Tweens.play(sprite, Tweens.position_2d([400, 180], 0.6))
```

An array with the wrong number of components rejects the start with `FAILED`.

</Compare>

Both move to the same position, and definition helpers accept the same forms. GDScript has no tuple syntax or C#'s compile-time endpoint checks.

| Animate | Sweet endpoint |
| --- | --- |
| Uniform scale | `Tweens.scale_2d([1.2, 1.2], 0.2)` |
| RGB color | `Tweens.modulate([1, 0.5, 0], 0.3)` |
| Named or HTML color | `Tweens.modulate(Color("tomato"), 0.3)` |

Three color components imply alpha 1. Arrays also work with `with_from()`, `with_to()`, and `with_by()`. For `Tweens.value()`, supply real vectors or colors so their type is known.

## Easing and delay

Arguments follow **endpoint, duration, ease, delay**. Times are seconds.

<Compare>

Fields name every setting.

```gdscript title="Clean: explicit & readable"
var arrive := Tweens.position_2d()
arrive.to_value = Vector2(400, 180)
arrive.duration = 0.6
arrive.ease = Out.CUBIC
arrive.delay = 0.2
```

---

Helper arguments take the same settings in order.

```gdscript title="Quick: convenient & concise"
var arrive := Tweens.position_2d([400, 180], 0.6, Out.CUBIC, 0.2)
Tweens.play(sprite, Tweens.position_2d([400, 180], 0.6, Out.CUBIC, 0.2))
```

A helper takes the same arguments on its own or inside `Tweens.play()`.

</Compare>

## More options

<Compare>

Set any other field on the definition. Definitions are mutable, so vary a copy with `with_*()` to leave the original unchanged.

```gdscript title="Structured"
var pulse := Tweens.scale_2d([1.2, 1.2], 0.2)
pulse.ping_pong = true
Tweens.play(sprite, pulse.with_repeats(2))
```

---

Chain `with_*()` copies on the helper inside the `Tweens.play()` call.

```gdscript title="Convenient"
Tweens.play(sprite, Tweens.scale_2d([1.2, 1.2], 0.2).with_ping_pong())
```

</Compare>
