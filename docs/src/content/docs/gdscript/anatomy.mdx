A definition describes one motion: where it goes, when it plays, how it paces, and what runs along the way. Every field has a default, so a definition sets only what it changes.

Examples use the global `Tweens` class in a node script, with targets inside the scene tree.

## Anatomy of a tween

<Moves>

```gdscript {"1":1} {"2":2} {"3":4} {"4":5}
var arrive := Tweens.position_2d([400, 180], 0.6, Out.CUBIC) \
	.with_on_end(func(_handle): print("Arrived"))

var movement := Tweens.play(sprite, arrive)
await movement.end
```

1. **Define.** A [definition](/gdscript/api/definitions/) holds the [endpoint](/gdscript/api/endpoints/), [timing](/gdscript/api/timing/), and [easing](/gdscript/api/easing/).
2. **React.** [Callbacks](/gdscript/api/callbacks/) run at fixed points of each playback.
3. **Start.** [Starting playback](/gdscript/api/start/) snapshots the definition and returns a [handle](/gdscript/api/handles/).
4. **Await.** `end` resumes with the [reason](/gdscript/api/handles/#tweensreason) playback ended.

</Moves>
