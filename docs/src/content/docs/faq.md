## Wait, Godot already has "Tween"...
Sure. But that gets out of paw really fast. Lots of typing, long lines of code, compromises, and in the end you can barely read what's going on. The stock tweens are also clunky to use with C#.

tweens.gd tries to make the code more readable, easier to type quickly when you need it, or with gusto and explicitly where you want it.
