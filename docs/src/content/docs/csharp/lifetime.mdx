A node owns the tweens started on it. Leaving the scene tree stops them automatically, including paused tweens.

## Target and owner

<CardGrid>
<Card title="Target">

The object receiving animated values: a node, material, or other supported object.

</Card>
<Card title="Owner">

The node whose lifetime controls playback. For node tweens, target and owner are the same.

</Card>
</CardGrid>

## Nodes

Start from `_Ready` or later, while the node is in the tree. Removal or reparenting that exits the tree ends its tweens.

To stop an entire branch, call `node.CancelTweens(includeChildren: true)`. This controls automatically scheduled playback.

## Pausing

| Mode | Playback follows |
| --- | --- |
| `Bound` (default) | The owner's ability to process |
| `SceneTree` | Tree pause |
| `Always` | Neither owner nor tree pause |

Set this policy in `PlaybackOptions.PauseMode` when starting playback. Pausing the handle always stops it.

**Try it:** pause the tree, then change the playback's pause mode.

<Aside type="note" title="Disabling process is different">

`SetProcess(false)` does not pause owned tweens. Bound playback follows `CanProcess()`, which depends on node process mode and tree pause.

</Aside>

## Resources

Give a material tween an owner node to stop it when that node leaves the tree, or a scene tree to keep it running for the tree's lifetime. Playback always targets the original resource, even if a mesh changes materials.

See [materials and shaders](/csharp/materials/) for examples. Tweens never duplicate or dispose the resources you supply.

## How playback ends

Every end settles the handle with a [completion reason](/csharp/cancellation/#why-it-ended). Keep handles only as long as you need them: a finished handle still references its target.

See [playback modes](/csharp/api/modes/) for callback suppression and [schedulers](/csharp/api/scheduler/) for manual playback.
