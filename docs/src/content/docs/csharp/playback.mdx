Every start returns a handle. Keep it to control that playback, or await its end before continuing.

Examples use `using Godot;` and `using tweens.gd;` in a Node method, with targets inside the scene tree.

## Pause, resume, cancel

<PlaybackRemote />

Cancelling keeps the latest value. `sprite.CancelTweens()` cancels all playback owned by that node.

## Await playback

```csharp
var movement = sprite.TweenPosition((400, 180), 0.6);
await movement.End;
```

The wait finishes after callbacks and cleanup. It also resumes when playback is cancelled or its owner leaves the tree.

<Aside type="caution" title="Continue only after arrival">

If the next action needs success, check `await movement.End == Reason.Completed`. The [cancellation guide](/csharp/cancellation/) shows a guarded sequence.

</Aside>



## Callbacks

Use a callback for a small synchronous reaction:

```csharp
var arrive = new Tweens.Position2D((400, 180), 0.6, Out.Cubic)
{
    OnEnd = _ => GD.Print("Arrived"),
};
sprite.Tween(arrive);
```

`OnEnd` runs on natural completion. `OnFinally` also runs when playback stops early or fails. See [callback order](/csharp/api/callbacks/#callback-order) for the full lifecycle.

## Errors

An easing, setter, or callback exception faults playback. Awaiting `End` throws; catch it in async Godot callbacks such as `_Ready`.

<Aside type="caution" title="Use Godot’s main thread">

Create and control tweens on the main thread. Await normally; avoid blocking with `.Wait()` or `.Result`, or moving engine access into `Task.Run`.

</Aside>
