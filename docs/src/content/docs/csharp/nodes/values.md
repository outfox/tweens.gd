---
title: Callback values
description: The eight callback value definitions, which write no property and deliver each sample to OnUpdate.
---

These target any `Node`, write no property, and deliver each sample to `OnUpdate`. See [custom tweens](/csharp/custom-tweens/#callback-values).

| Definition | Shorthand | Value |
| --- | --- | --- |
| `Tweens.Color` | `TweenColor` | Color |
| `Tweens.Double` | `TweenDouble` | double |
| `Tweens.Float` | `TweenFloat` | float |
| `Tweens.Quaternion` | `TweenQuaternion` | Quaternion |
| `Tweens.Rect2` | `TweenRect2` | Rect2 |
| `Tweens.Vector2` | `TweenVector2` | Vector2 |
| `Tweens.Vector3` | `TweenVector3` | Vector3 |
| `Tweens.Vector4` | `TweenVector4` | Vector4 |
