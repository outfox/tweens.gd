## Units and constraints

- Rotation and skew use radians, and positions, sizes, and offsets use the
  Godot units of each property.
- `Node2D` global scale and skew follow Godot's parent-relative decomposition.
  Under a nonuniformly scaled parent they aren't independent: changing skew can
  also change apparent scale. Axis definitions (`...X`, `...Y`) preserve the other
  components of the property they write, but not every derived transform
  component.
- Particle `SpeedScale` and `Lifetime` are `double`, matching Godot's properties.
  Emission parameters depend on the configured emitter modes and materials.
- Path definitions require a `PathFollow2D` under a `Path2D` with a nonempty
  curve. `ProgressRatio` is normalized; `Progress` is a distance. The node still
  controls looping and wrapping.
- Sprite `Frame` needs its sprite frames and animation set up first.
