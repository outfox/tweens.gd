When the catalog has no suitable property, animate a callback value or supply your own read and write operations.

Examples use `using Godot;` and `using tweens.gd;` in a Node method, with targets inside the scene tree.

## Callback values

```csharp
owner.Tween(new Tweens.Float
{
    From = 10,
    To = 100,
    Duration = 1,
    OnUpdate = (_, sample) => label.Text = MathF.Round(sample).ToString(),
});
```

The label counts from 10 to 100. The owner controls playback's lifetime; the callback receives each sample.

## Custom properties

```csharp title="HealthBar.cs"
public partial class HealthBar : Node2D
{
    public float Fill { get; set; } = 1;

    static readonly Tweens.Property<HealthBar, float> Drain = new(
        bar => bar.Fill, (bar, value) => bar.Fill = value, Interpolators.Float)
        { Duration = 0.4, Ease = InOut.SmootherStep };

    public void SetHealth(float fraction) => this.Tween(Drain with { To = fraction });
}
```

`Tweens.Property<TTarget, TValue>` uses a typed getter, setter, and interpolator.

## Extend a binding

For setup or cleanup per playback, derive from `TweenDefinition<TTarget, TValue>`. Its hooks read, write, prepare, restore, and release a binding. Each start gets its own snapshot; referenced configuration stays shared unless you copy it yourself.

<Aside type="caution" title="Release what your start owns">

Keep per-playback state in the playback copy. Release only resources created or owned by that copy. See the reference for hook order and failed preparation.

</Aside>
