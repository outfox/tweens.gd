Duration sets how long a motion takes; delay sets when it begins. Add ping-pong and repeats for idle motion that runs itself.

Examples use `using Godot;` and `using tweens.gd;` in a Node method, with targets inside the scene tree.

## Loop forever

```csharp
var pulse = new Tweens.Scale2D(1.1, 0.8, InOut.Sine)
{
    PingPong = true,
    Repeats = TweenOptions.Infinite,
};

sprite.Tween(pulse);
```

The sprite grows for 0.8 seconds, shrinks for 0.8 seconds, and repeats until cancelled or removed from the tree.

## Count cycles

| Set | Result |
| --- | --- |
| `Repeats = 2` | Three cycles: the first plus two repeats |
| `PingPong = true` | Each cycle goes forward, then back |
| `PingPongInterval` | Wait at the far endpoint |
| `RepeatInterval` | Wait between cycles |

**Try it:** add a return leg and drag the timeline to see where the intervals fit.

## Fill and restoration

The default keeps the final value. For an entrance with a delay, use `Fill = FillMode.Both` so the starting value is visible while waiting.

**Try it:** switch fill modes to compare waiting and completion.

<FillModes />

<Aside type="note" title="Cancellation keeps the current value">

Restoration applies on natural completion. Cancelling keeps the latest sample, regardless of fill mode.

</Aside>

## Process and physics

Playback uses process frames by default. Pass `PlaybackOptions` at the start for physics updates or unscaled time.

The [timing reference](/csharp/api/timing/) lists every option, fill mode, and validation rule. [Playback modes](/csharp/api/modes/) control the clock; [ownership](/csharp/lifetime/) controls pausing with the scene.
