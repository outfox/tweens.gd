Add tweens.gd to a Godot C# project. Choose the shared addon for both languages, or NuGet for C# alone.

## Choose an install

<CardGrid>
<InstallCard title="Godot Asset Store" logo="godot-asset-store" href="https://store.godotengine.org/asset/outfox/tweens/">

Get the shared addon with support for both C# and GDScript.

1. Download it from the [Godot Asset Store](https://store.godotengine.org/asset/outfox/tweens/).
2. Unpack it into your project root, keeping the entire `addons/tweens_gd/` directory.

</InstallCard>
<InstallCard title="NuGet" logo="nuget" href="https://www.nuget.org/packages/tweens.gd">

Add the pure C# library through your package manager.

```powershell
dotnet add package tweens.gd
```

</InstallCard>
</CardGrid>

## Build your project

Build your game with Godot 4.7.2 .NET. No plugin activation or autoload is required.

<Aside type="caution" title="Choose one C# source">

Installing both NuGet and the addon's C# sources creates duplicate types. For a mixed setup, [exclude the addon sources](/advanced-development/#using-nuget-together-with-the-gdscript-addon).

</Aside>

The library is free and open source under the [MIT license](https://github.com/outfox/tweens.gd/blob/main/LICENSE). See [compatibility](/compatibility/) for validated engines and exports.
