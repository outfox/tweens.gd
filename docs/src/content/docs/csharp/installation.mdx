tweens.gd is free and libre open source under the [MIT license](https://github.com/outfox/tweens.gd/blob/main/LICENSE).
You can build it from source or get prebuilt versions through these official channels.

## Let's... *ease* into it

Choose one of these two methods:

<InstallOptions>
<div slot="store">

### Godot Store

Get the shared addon with support for both C# and GDScript.

1. Download it from the [Godot Store](https://store.godotengine.org/asset/outfox/tweens/).
2. Unpack it into your project root, keeping the entire `addons/tweens_gd/` directory.

</div>
<div slot="alternative">

### NuGet

Add the pure C# library through your package manager.

```powershell
dotnet add package tweens.gd
```

</div>
</InstallOptions>

## Build your project

Build your game with Godot 4.7.2 .NET or later. No plugin activation or autoload is required.

Once tweens.gd is installed and Godot is running, you're ready to write
[your first tween](/csharp/quickstart/).

## Odds and ends

*Psst, hey:* Bring your Godot C# game & tweens to the web with [2dog 🦴](https://2dog.dev), which supports
publishing to `browser-wasm` and many other useful tricks. Free, libre open source, like all good things Godot.
