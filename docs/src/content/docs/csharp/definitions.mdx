A definition describes motion. Each start copies its settings into independent playback, so one definition can animate many nodes.

Examples use `using Godot;` and `using tweens.gd;` in a Node method, with targets inside the scene tree.

## Define once, start twice

```csharp
var nudge = new Tweens.Position2D
{
    By = new Vector2(80, 0),
    Duration = 0.2,
    Ease = Out.Cubic,
};

sprite1.Tween(nudge);
sprite2.Tween(nudge);
```

Both sprites move 80 pixels right from their own positions. Each start returns its own handle.

<Aside type="tip" title="Keep reusable motion nearby">

Store a shared definition in a `static readonly` field. The generated definitions are readonly record structs.

</Aside>

## Choose the endpoints

| Choose | Result |
| --- | --- |
| `To` | Move to a destination |
| `From` only | Animate an entrance to the value set in the scene |
| `By` only | Add an offset, preserving other movement |

An omitted endpoint uses the property's value when playback starts, before any delay.

<Aside type="note" title="Relative motion">

Use `To` or `By`, not both. Leave `From` out when an offset should add to other movement.

</Aside>

## Vary one start

Replace the second start with `sprite2.Tween(nudge with { Duration = 0.6 });`.

The copy takes longer; the original still takes 0.2 seconds. Already running tweens keep their settings.

**Try it:** change the second duration and play both.
