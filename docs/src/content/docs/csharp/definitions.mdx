A definition describes a motion independently of the node playing it. Keep one
definition for motion you reuse; each start gets its own snapshot.

Examples assume `using Godot;` and `using tweens.gd;`, and run on Godot's main
thread with nodes inside the tree.

## Define once, start twice

Keep the definition in a `static readonly` field so every instance can use it:

```csharp title="Crate.cs"
public partial class Crate : Node2D
{
    static readonly Tweens.Position2D Nudge = new()
    {
        By = new Vector2(80, 0),
        Duration = 0.2,
        Ease = Out.Cubic,
    };

    public void PushPair(Node2D first, Node2D second)
    {
        first.Tween(Nudge);
        second.Tween(Nudge);
    }
}
```

Both nodes move 80 pixels right from their own positions. Editing `Nudge` tunes
the motion in one place. Starting it returns a separate handle for each node.

## Leave out `From` or `To`

Use `To` for a destination, or `From` for an entrance:

| Definition | Motion |
| --- | --- |
| `new Tweens.Position2D { To = new Vector2(400, 180), Duration = 0.4 }` | Move from the current position to a fixed destination |
| `new Tweens.Scale2D { From = Vector2.Zero, Duration = 0.4 }` | Grow from zero to the scale set in the scene |

An omitted endpoint is read from the property **when you start the tween**, before
any delay. Set both endpoints when both must be fixed.

## Move by an offset with `By`

`Nudge` uses `By` to add an offset. Other changes to the property are kept while
it plays: two overlapping nudges move a crate 160 pixels in total.

Use either `To` or `By`. Leave `From` out for this additive motion; setting it
makes the tween run between fixed endpoints, from `From` to `From + By`.

## Vary a start with `with`

In `PushPair`, replace the second call with
`second.Tween(Nudge with { Duration = 0.6 });`.

`with` creates a modified value. The second node takes longer, but `Nudge` still
has a duration of 0.2 seconds. Neither copy changes a tween already playing.

**Try it:** change the second node's duration and press **Play both**. Both travel
the same distance; the first always takes 0.2 seconds.
