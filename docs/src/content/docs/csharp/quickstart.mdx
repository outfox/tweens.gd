Make a sprite glide 240 pixels to the right, then fade out. You'll write one
short script and run it in a scene.

<Steps>

1. [Install the library](/csharp/installation/) in your Godot C# project.

2. Create a scene with a `Sprite2D`, give it a texture, and place it where there
   is room to move right in the viewport.

3. Attach the script below as `MoveAndFade.cs`, then play the scene.

</Steps>

<span id="the-script-line-by-line" />

## Move, then fade

<Moves>

```csharp title="MoveAndFade.cs" {"1":8-13} {"2":15} {"3":16} {"4":18}
using Godot;
using tweens.gd;

public partial class MoveAndFade : Sprite2D
{
    public override async void _Ready()
    {
        var arrive = new Tweens.Position2D
        {
            To = Position + new Vector2(240, 0),
            Duration = 0.6,
            Ease = Out.Cubic,
        };

        var movement = this.Tween(arrive);
        await movement.End;

        await this.TweenModulateAlpha(0, 0.3).End;
    }
}
```

1. **Choose the move.** `arrive` moves the sprite 240 pixels right in 0.6 seconds.
   `Out.Cubic` makes it slow into place.
2. **Start moving.** `this.Tween(arrive)` plays the motion on this sprite.
   Keep its handle in `movement` to wait for it.
3. **Wait before fading.** `await movement.End` lets the movement finish before
   the script continues.
4. **Fade out.** `TweenModulateAlpha(0, 0.3)` lowers the sprite's opacity to zero
   over 0.3 seconds. This shorthand defines and starts the fade in one call.

</Moves>


Experiment with the values in the tween definition to get a feel for duration.
