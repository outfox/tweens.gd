Make a sprite glide 240 pixels to the right, then fade out. You'll write one
short script and run it in a scene.

<Steps>

1. [Install the library](/csharp/installation/) in your Godot C# project.

2. Create a scene with a `Sprite2D`, give it a texture, and place it where there
   is room to move right in the viewport.

3. Attach the script below as `MoveAndFade.cs`, then play the scene.

</Steps>

## Move, then fade

<Moves>

```csharp title="MoveAndFade.cs" {"1":8} {"2":10} {"3":11} {"4":13}
using Godot;
using tweens.gd;

public partial class MoveAndFade : Sprite2D
{
    public override async void _Ready()
    {
        var arrive = new Tweens.Position2D(Position + new Vector2(240, 0), 0.6, Out.Cubic);

        var movement = this.Tween(arrive);
        await movement.End;

        await this.TweenModulateAlpha(0, 0.3).End;
    }
}
```

1. **Define.** Move 240 pixels right in 0.6 seconds; `Out.Cubic` slows into place.
2. **Play.** Start on this sprite and keep the returned handle.
3. **Wait.** Continue when movement ends.
4. **Fade.** Animate opacity to zero over 0.3 seconds.

</Moves>


<Aside type="tip" title="Try it">

Change `0.6` to `1.2` to make the move take twice as long. Swap `Out.Cubic` for `InOut.Sine` to soften both ends.

</Aside>
