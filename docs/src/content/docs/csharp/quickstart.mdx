Move a sprite, then fade it out once it arrives. Along the way you define a
tween, start it on the sprite, and await it before continuing.

<Steps>

1. [Install the library](/csharp/installation/) in your Godot C# project.

2. Create a scene with a `Sprite2D` and give it a texture.

3. Attach this script as `MoveAndFade.cs`, then play the scene. The sprite glides
   240 pixels to the right, settles, and fades out.

</Steps>

## The script, line by line

<Moves>

```csharp title="MoveAndFade.cs" {"1":8-13} {"2":15} {"3":16} {"4":18}
using Godot;
using tweens.gd;

public partial class MoveAndFade : Sprite2D
{
    public override async void _Ready()
    {
        var arrive = new Tweens.Position2D
        {
            To = Position + new Vector2(240, 0),
            Duration = 0.6,
            Ease = EaseType.CubicOut,
        };

        var movement = this.Tween(arrive);
        await movement;

        await this.TweenModulateAlpha(0, 0.3);
    }
}
```

1. **Define.** `Tweens.Position2D` names the property, and the initializer holds
   the endpoint, duration, and easing. `From` is left out, so the tween starts
   wherever the sprite is. Keep the `Tweens.` prefix. Some definitions share a
   name with a Godot type, such as `Vector2`, and the prefix tells them apart.
2. **Start.** `this.Tween(arrive)` starts playback and returns a handle. The
   first tween sets up its own runner, so there's no autoload to add.
3. **Await.** `await movement` waits until playback ends. Here we ignore the
   returned reason and continue with the fade.
4. **Shorthand.** `TweenModulateAlpha(0, 0.3)` builds and starts a definition in
   one call, which is handy for one-off motion. If you start the same motion in
   several places or expect to adjust it, write a definition instead, so its
   settings live in one field.

</Moves>

Start tweens from `_Ready` or later, on Godot's main thread.

Await also resumes after cancellation. For an animation that can be interrupted,
[check the reason before starting the next step](/csharp/cancellation/).

## Control it while it plays

Keep the handle to pause, resume, or cancel:

```csharp
var movement = sprite.TweenPosition(new Vector2(400, 180), 0.6);
movement.Pause();
movement.Resume();
movement.Cancel();
```

Cancelling keeps the latest value. To stop every tween the sprite and its
descendants own, call `sprite.CancelTweens(includeChildren: true)`.

## Make it reusable

`arrive` lives inside `_Ready`, so nothing else can use it. Move it to a field
and compute the endpoint for each start with `with`, and other nodes can start
the same motion. The next page, [definitions](/csharp/definitions/), shows
how.
