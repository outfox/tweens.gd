A definition describes one motion: where it goes, when it plays, how it paces, and what runs along the way. Every field has a default, so a definition sets only what it changes.

Examples use `using Godot;` and `using tweens.gd;` in a Node method, with targets inside the scene tree.

## Anatomy of a tween

<Moves>

```csharp {"1":1} {"2":3} {"3":6} {"4":7}
var arrive = new Tweens.Position2D((400, 180), 0.6, Out.Cubic)
{
    OnEnd = _ => GD.Print("Arrived"),
};

var movement = sprite.Tween(arrive);
await movement.End;
```

1. **Define.** A [definition](/csharp/api/definitions/) holds the [endpoint](/csharp/api/endpoints/), [timing](/csharp/api/timing/), and [easing](/csharp/api/easing/).
2. **React.** [Callbacks](/csharp/api/callbacks/) run at fixed points of each playback.
3. **Start.** [Starting playback](/csharp/api/start/) snapshots the definition and returns a [handle](/csharp/api/handles/).
4. **Await.** `End` completes with the [reason](/csharp/api/handles/#reason) playback ended.

</Moves>
