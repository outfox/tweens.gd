Easing controls how a tween speeds up and slows down without changing how long it
takes. The default, `EaseType.Linear`, moves at constant speed, which rarely suits
characters or UI. Pick an ease for every definition.

## Choose an ease

| Motion | Try | Why |
| --- | --- | --- |
| Arriving, settling into place | `CubicOut`, `QuartOut` | Starts fast, lands gently |
| Leaving the screen | `CubicIn`, `QuadIn` | Gathers speed on the way out |
| Moving between two resting spots | `SmootherStep`, `SineInOut` | Eases out of rest and into rest |
| A playful pop or emphasis | `BackOut`, `ElasticOut` | Overshoots, then settles |
| Dropping onto a surface | `BounceOut` | Lands with bounces |
| Constant motion, such as spinners or progress | `Linear` | No acceleration |

`Out` eases decelerate, `In` eases accelerate, and `InOut` eases do both.
`Linear`, `SmoothStep`, and `SmootherStep` have no variants. Each of the ten
families below comes in all three, such as `EaseType.CubicIn`, `EaseType.CubicOut`,
and `EaseType.CubicInOut`.

## Compare the curves

<EasingPlayground />

| Family | Character |
| --- | --- |
| `Sine` | Gentle acceleration and deceleration |
| `Quad`, `Cubic`, `Quart`, `Quint` | Increasingly pronounced polynomial curves |
| `Expo` | Strong exponential acceleration and deceleration |
| `Circ` | Circular curve |
| `Back` | Overshoots an endpoint |
| `Elastic` | Oscillates around an endpoint |
| `Bounce` | Repeated bounces |
| `SmoothStep`, `SmootherStep` | S-curves that start and stop at zero speed; `SmootherStep` also starts and stops with zero acceleration |

Back and elastic weights aren't clamped. Overshoot suits motion, but native
property limits still apply to constrained values such as alpha or ranges.

## Skew the timing

Set `Skew` to feed normalized time through `Math.Pow(t, Skew)` before the easing
function. It defaults to `1`, which leaves the easing unchanged. Values above `1`
rear-load the curve; values between `0` and `1` front-load it. For example, at
`t = 0.25`, a skew of `2` passes `0.0625` to the ease, while `0.5` passes `0.5`.

```csharp
var movement = sprite.Tween(new Tweens.Position2D
{
    To = new Vector2(300, 120),
    Duration = 0.5,
    Ease = EaseType.CubicOut,
    Skew = 2,
});
```

`Skew` must be finite and greater than zero. It applies to built-in eases,
`EaseFunction`, and Godot `Curve` samples. Duration and the handle's raw
`Progress` stay unchanged, and ping-pong retraces the same skewed curve in
reverse. Both time endpoints are preserved. For bounce, elastic, and other
non-monotonic eases, skew shifts when their features happen; it does not remove
bounces or overshoot.

## Custom functions and curves

For a shape the built-in eases don't cover, pass a function that maps normalized
progress to a weight:

```csharp
var eased = sprite.TweenPosition(new Vector2(300, 120), 0.5,
    options => options.EaseFunction = t => t * t);
```

`EaseFunction` overrides `Ease`. A Godot `Curve` can override `Ease` instead. It's
sampled with normalized time from 0 to 1, and each playback gets its own
duplicate. Pick one of `EaseFunction` and `Curve`, since setting both is rejected.
If an easing function throws, the tween faults.
