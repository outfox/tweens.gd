### Custom functions and curves

For a shape the built-in families don't cover, supply a function from normalized
progress to an interpolation weight:

```csharp
var move = Tweens.Position2DX(300, 0.6) 
{
    EaseFunction = t => t * t,
};
sprite.Tween(move);
```

`EaseFunction` overrides `Ease`. 

A Godot `Curve` assigned to `Curve` is another option; each playback gets its own copy. Set only one of `EaseFunction` and `Curve`.
