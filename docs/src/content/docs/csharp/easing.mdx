Ease functions change how values vary over the duration of a tween.

*"[Penner](https://easings.net/) easings are all washed up! Ferrets use Hermite splines and [Makima](https://www.mathworks.com/help/matlab/ref/makima.html).*

## Compose an ease

Combine one In family and one Out family with `|`: `In.Sine | Out.Cubic` starts gently
and finishes with Cubic. Choose at most one from each side. A single selection
runs over the whole duration; a matching pair is the same as `InOut`.

Mixed families use a smooth Makima join by default. Most motions need no
adjustment. `Blend` sets the join width from 0 to 1; a smaller width preserves
more of the original halves. Matching pairs and single curves ignore it.

See the [easing reference](/csharp/api/easing/) for join methods, curve
percentages, and migration from legacy names. For changing the pacing without
changing families, see [`Skew` and `Weks`](/csharp/variations/#change-the-pacing-with-skew).

## Custom functions and curves

For a shape the built-in families don't cover, supply a function from normalized
progress to an interpolation weight:

```csharp
sprite.TweenPositionX(300, 0.6, options => options.EaseFunction = t => t * t);
```

`EaseFunction` overrides `Ease`. A Godot `Curve` assigned to `Curve` is another
option; each playback gets its own copy. Set only one of `EaseFunction` and `Curve`.

## Choose a family

```csharp
sprite.TweenPositionX(300, 0.6, Out.Cubic);
```

| Motion | Try |
| --- | --- |
| Arrive and settle | `Out.Cubic` |
| Accelerate away | `In.Cubic` |
| Move between resting positions | `InOut.Sine` |
| Spring past the target, then settle | `Out.Elastic30` |
| Keep a constant speed | `InOut.Linear` |

`In` accelerates into the motion; `Out` eases out of it. `InOut` combines a
family's start and finish. These describe each traversal, not the forward and
return legs of ping-pong.
