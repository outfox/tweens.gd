There's more than one way to tween a ferret!

## Definitions: Structured vs. Convenient


<Compare>

The <u>**Structured**</u> syntax creates a strongly typed, immutable record struct definition to reuse, or to vary with the `with` keyword.

```csharp title="Structured"
var arrive = new Tweens.Position2D((400, 180), 0.6, Out.Cubic);

sprite.Tween(arrive with { Delay = 0.1 });
```

```csharp title="Fully Structured"
var arrive = new Tweens.Position2D
{
    To = new (400, 180),
    Duration = 0.6,
    Ease = Out.Cubic,
    Delay = 0.1,
};

sprite.Tween(arrive);
```

---

The <u>**Convenient**</u> defines and starts a local animation through an extension method, available on a wide variety of nodes and their descendants.

```csharp title="Convenient"
sprite.TweenPosition((400, 180), 0.6, Out.Cubic, 0.1);
```

</Compare>

These are alternative ways to start the same motion. Both return a handle when played.

## Values: Safe vs. Sweet

<Compare>

A Godot value states the endpoint's type; a tuple leaves it out. The compiler checks both, down to the number of components and that each one is a number.

```csharp title="Safe: explicit type or tuple"
sprite.TweenPosition(new Vector2(400, 180), 0.6);
sprite.TweenPosition((400, 180), 0.6);
```

---

Arrays are checked when the tween is created: a mismatched length throws `ArgumentException`.

The array syntax exists since they read closest to GDScript.

```csharp title="Sweet: array"
sprite.TweenPosition([400, 180], 0.6);
```

</Compare>

All three move to the same position, and structured constructors accept the same forms.

| Animate | Shorter endpoint | Checked |
| --- | --- | --- |
| Uniform scale | `sprite.TweenScale(1.2, 0.2)` | By the compiler |
| RGB color | `label.TweenModulate((1, 0.5, 0), 0.3)` | By the compiler |
| Named or HTML color | `label.TweenModulate("tomato", 0.3)` | When the tween is created |

Three color components imply alpha 1. Numeric endpoints need no `f` suffix.

## Easing and delay

Arguments follow **endpoint, duration, ease, delay**. Times are seconds; C# also accepts `TimeSpan`.

<Compare>

An initializer names every setting.

```csharp title="Clean: explicit & readable"
var arrive = new Tweens.Position2D
{
    To = new Vector2(400, 180),
    Duration = 0.6,
    Ease = Out.Cubic,
    Delay = 0.2,
};
```

---

Arguments take the same settings in order.

```csharp title="Quick: convenient & concise"
var arrive = new Tweens.Position2D((400, 180), 0.6, Out.Cubic, 0.2);
sprite.TweenPosition((400, 180), 0.6, Out.Cubic, 0.2);
```

Constructors and convenient calls take the same arguments.

</Compare>

## More options

<Compare>

Set any other option in an initializer, and vary a copy with `with`.

```csharp title="Structured"
var pulse = new Tweens.Scale2D(1.2, 0.2) { PingPong = true };
sprite.Tween(pulse with { Repeats = 2 });
```

---

Set any other option in a configure callback, which receives the definition before it starts.

```csharp title="Convenient"
sprite.TweenScale(1.2, 0.2, options => options.PingPong = true);
```

</Compare>
